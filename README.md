## Overview

On the first day of the Trainee Program, I was introduced to the fundamentals of Python programming. The session covered the core building blocks needed to read, write, and understand basic Python programs.

---

## What I Learned

**Basics**
Covered the foundational elements of Python — variables, data types, operators, and keywords. Learned how data is stored, what types Python supports, and how operations are performed on values. Also practiced taking input from the user and displaying output.

**Conditional Statements**
Learned how to control the flow of a program based on conditions using `if`, `elif`, and `else`.

**Loops**
Understood how to repeat tasks using `for` and `while` loops, along with control keywords like `break`, `continue`, and `pass`.

**Exception Handling**
Learned how to handle runtime errors gracefully so the program doesn't crash. Covered both Python's built-in exceptions and how to define custom exceptions for specific use cases.

**Functions**
Explored how to write reusable blocks of code. Topics included variable scope, passing flexible arguments, decorators, recursion, and generators.

**File Handling**
Learned how to open and read data from a text file using Python's built-in file handling methods.
